Uma doação pontual ajuda hoje. Uma doação mensal ajuda a planejar o ano. Para a maioria das organizações sociais, construir uma base de **doadores recorrentes** é a forma mais segura de ter previsibilidade de receita.

## 1. Peça de forma clara e concreta

- Mostre **o que a doação mensal paga**: "com R$ 30 por mês, uma criança tem reforço escolar por um mês".
- Ofereça **três ou quatro valores sugeridos** e a opção de escolher outro.
- Explique que dá para **cancelar quando quiser**. Isso reduz o medo de se comprometer.

## 2. Facilite o caminho

- Página de doação simples, que funcione bem no celular.
- Pagamento por cartão para a recorrência, com cobrança automática.
- Poucos campos no formulário: só o necessário.

## 3. Agradeça rápido, e de verdade

- E-mail de agradecimento logo após a primeira doação.
- Uma mensagem pessoal da equipe ou de alguém atendido pelo projeto, quando possível.
- Lembre a pessoa de **como acompanhar** o impacto.

## 4. Mostre o impacto com frequência

Doadores recorrentes cancelam, principalmente, quando deixam de ver resultado. Crie uma rotina:

| Frequência | O quê |
| --- | --- |
| Mensal | uma atualização curta: foto, número, história |
| Trimestral | um resumo do que foi feito com as doações |
| Anual | relatório com resultados, finanças e próximos passos |

## 5. Trate os dados com cuidado

Os dados dos doadores são pessoais e estão protegidos pela **LGPD** (Lei 13.709/2018). Use-os só para a finalidade informada, guarde com segurança e respeite quem pede para não receber comunicações.

## 6. Acompanhe os cancelamentos

- Pergunte, de forma simples, **por que** a pessoa cancelou.
- Ofereça alternativas: reduzir o valor, pausar, trocar de causa.
- Analise os motivos a cada trimestre e ajuste a comunicação.

## 7. Envolva os doadores

- Convide para conhecer o projeto ou para eventos.
- Crie campanhas de aniversário ou de fim de ano em que o doador mensal convida amigos.
- Reconheça quem doa há mais tempo.

## Indicadores para acompanhar

| Indicador | O que mostra |
| --- | --- |
| Número de doadores mensais ativos | o tamanho da base |
| Receita recorrente prevista no mês | a previsibilidade |
| Taxa de cancelamento mensal | se a base está saudável |
| Tempo médio de permanência | a fidelidade dos doadores |
| Conversão de pontuais em mensais | a eficácia do pedido |
